00優先度の定義

各機能カテゴリに付与した3段階の優先度。移植困難性（Windows専用API・COM・DLL ABIへの依存度）と、エディタとしての本質的な重要度の両方を勘案して判断している。

必須

これがないとテキストエディタとして成立しないコア機能。

重要

サクラエディタらしさの中核。初期リリースで欲しい機能。

後回し可

Windows専用技術に強く依存、またはニッチで初期は見送れる機能。

04検索・正規表現機能

通常検索

CSearchStringPattern が独自の高速文字列検索（Sunday Quick法／KMP法をビルドオプションで選択）を実装。大文字小文字区別オプションあり。

agent/CSearchAgent.*

正規表現検索

CBregexp がPerl5互換の BREGEXP.DLL（Windows専用）をCDllHandler経由でラップ。Onigmo/bregonigへの一本化で移植性は高い部類。

extmodule/CBregexp.cpp

Migemo検索

ローマ字入力のままインクリメンタルに日本語を検索。C/Migemo DLLをシングルトンでロードする外部DLL依存機能。

extmodule/CMigemo.cpp

Grep（ファイル横断検索）

SGrepOptionでサブフォルダー再帰・出力スタイル（Normal/WZ風/結果のみ）・ヒット行/非ヒット行出力・クリップボードからの置換・バックアップ付き置換を制御。

agent/CGrepAgent.*, CGrepEnumFiles/Folders/Keys

05その他の主要機能

マクロ機能（3系統）

WSH：ActivScp.h（COM ActiveScript）に全面依存、JScript/VBScript実行。PPA：外部PPA.DLLによるPascal系インタープリタ。Python：外部DLLロード。いずれもWindows専用技術が前提。

macro/CWSH*.cpp, CPPA.cpp, CPythonMacroManager.cpp

プラグイン機能

Win32 DLLを独自ABI（DllPlugHandler関数ポインタ）で直接呼び出す形式。plugin.defでJack（拡張ポイント）とコマンドを宣言。

plugin/CDllPlugin.cpp, CPluginManager, CJackManager

矩形（ボックス）選択

カーソル移動系コマンド全種に対応する_BOX版が用意され、Undo/Redoも含め完全サポート。実装自体のWindows依存は薄い。

CViewCommander_Select.cpp

差分比較

外部diffutils（GNU diffutils, submodule）と連携し2ファイル間の差分を色分け表示、次/前の差分へジャンプ。

docplus/CDiffManager.*, CDlgDiff.*

自動保存／バックアップ／自動再読込

CAutoSaveAgent（タイマーベース自動保存）、CBackupAgent（保存前フック）、CAutoReloadAgent（外部更新検知：問い合わせ/通知/無視/自動ロード）。CDocListenerイベントフックに乗る設計でWindows依存は薄い。

sakura_core/agent/

タグジャンプ

外部Ctags（submodule）連携でタグファイル作成・ジャンプ・ジャンプバック。開発者向けのニッチ機能でLSP的な代替も検討可。

CViewCommander_TagJump.cpp

06Mac版MVP優先度マップ

カテゴリ横断で3段階に振り分けた一覧。境界的なものは「重要」列の末尾に注記付きで配置している。

必須5
  • ファイル操作新規/開く/保存/文字コード・改行コード指定
  • 編集操作入力/Undo・Redo/削除/インデント/トリム/ソート
  • カーソル移動・通常選択
  • クリップボード（基本形）HTML色付きコピー等は重要止まり
  • モード切替挿入/上書き・文字コード・改行コード
重要13
  • シンタックスハイライト基盤主要言語から着手
  • 検索・置換（通常＋正規表現）
  • 矩形選択
  • 対括弧強調・主要言語のアウトライン解析
  • ブックマーク
  • Grep
  • タブ・ウィンドウ分割2プロセスモデル自体は再設計前提
  • 設定・カスタマイズフォント/配色/キーバインド
  • 自動保存/バックアップ/自動再読込
  • 通常インクリメンタルサーチ
  • キーマクロ（操作記録・再生）OS非依存、軽量版から
  • 差分比較境界：後回し可とも判断できる

  • Migemo検索

  • 印刷・印刷プレビュー
  • ニッチ言語定義COBOL/アセンブラ/PL-SQL/CORBA IDL等
  • 外部コマンド実行SQL*Plus連携等

07MVP候補リスト（推奨実装順）

土台となる描画エンジン・ドキュメントモデルの実現性検証を兼ねて、この順で着手するのが妥当と判断した候補。

  1. ファイルの新規作成／開く／保存／名前を付けて保存、文字コード・改行コード（CRLF/LF/CR）の判定と指定
  2. 基本編集操作（入力・削除・Undo/Redo・コピー・カット・ペースト）
  3. カーソル移動（文字・単語・行・段落・ページ単位）と範囲選択
  4. 矩形（ボックス）選択と矩形貼り付け
  5. 検索・置換（通常検索＋正規表現検索、インクリメンタルサーチ）
  6. 主要言語（C/C++, Python, HTML, JSON/設定ファイル系など）のシンタックスハイライト基盤（キーワード強調、コメント/文字列判定）
  7. 主要言語のアウトライン解析（関数/クラス一覧パネル）
  8. 対括弧の強調表示
  9. ブックマーク機能（設定／次へ／前へ／一覧）
  10. Grep（複数ファイル横断検索・置換）
  11. タブによる複数ファイル管理と簡易ウィンドウ分割
  12. 型別（言語別）設定とアプリ共通設定（フォント、配色、タブ幅、折返し）のカスタマイズ
  13. 自動保存・自動バックアップ
  14. キーバインドのカスタマイズ
  15. シンプルな操作記録・再生（スクリプトエンジンなしの軽量キーマクロ相当）
MVP後に回す判断とした機能： マクロ（WSH/PPA/Python）、DLLプラグイン、タグジャンプ、Migemo検索、印刷、ニッチ言語定義、外部コマンド連携。いずれもWindows専用技術への依存度が高いか、利用者が限定的なため段階的拡張フェーズが妥当。
